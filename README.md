# 🎥 OBS Studio Web Pro - Lightweight & Zero-Lag Edition

Screen Recorder jo ab laptop ke hardware par 0% extra load ke sath bilkul smooth chalta hai.

---

## ⚡ Nayi Fixes:
1. **Widescreen Rectangular Camera (Square Masla Theek):**
   - Video download hone ke baad ab camera hargiz Square nahi hoga, balki jesa aapko screen par Widescreen rectangle nazar aata hai, bilkul wesa hi 16:9 rectangle record hoga!
   - `object-fit: cover` rendering add kar di gayi hai jis se chehra kabhi stretch ya squish nahi hota.
2. **Lag Free:**
   - 30 FPS aur 3.5 Mbps HD bitrate se zero lag recording.
3. **Clean Borderless Facecam:**
   - Red border aur 4 corners hata diye gaye hain.
   - Mouse wheel se chota / bara karein, ya quick buttons `[🔍-]` `[🔍+]` dabayein.

---

## 🚀 Run Karne Ka Tareeqa:
1. **`Run Screen Recorder.bat`** par double-click karein.
2. Browser me **`Ctrl + F5`** (Hard Refresh) dabayein.
3. Screen & Facecam on kar ke **"Start Recording"** dabayein!
